## B. 입소자 본인 또는 법정대리인용 (핵심)

### 1. 수집하는 민감정보 항목

| 민감정보 구분 | 세부 항목 | 근거 법령 |
|---|---|---|
| **생체정보** | 얼굴 사진 (기준 사진 1~5장) | 개인정보보호법 제23조, 시행령 제18조 |
| **생체정보** | 얼굴 특징 벡터 (수치 표현, 재식별 가능) | 위와 같음 |
| **건강정보** | 의료·복약 관련 메모 (예: 고혈압, 치매, 알러지 등) | 위와 같음 |

### 2. 수집·이용 목적

**생체정보 (얼굴)**
- 업로드된 단체 사진에서 입소자를 자동 식별하여 해당 입소자의 보호자에게만 선별적으로 공유
- 다른 입소자·직원의 사진이 잘못 공유되는 것을 방지
- 사진 분류 정확도 개선을 위한 기술적 개선 (**익명화된 임베딩 벡터에 한함**, 원본 사진은 개선에 사용하지 않음)

**건강정보**
- 돌봄 기록·복약 일정·식이 주의사항을 시설 직원이 참조
- 보호자 대시보드에서 최근 건강 상태 확인 (보호자에게만 공개)

### 3. 보유·이용 기간

| 항목 | 기간 |
|---|---|
| 얼굴 사진·벡터 | **입소자의 퇴소·사망일 또는 본 동의 철회일부터 30일 이내 파기** |
| 건강 메모 | 위와 같음 |
| 업로드된 일반 사진 | 시설이 별도 삭제하거나 서비스 계약 종료 후 30일 이내 파기 (민감정보 동의서가 아닌 서비스 이용약관의 파기 정책을 따름) |

### 4. 민감정보의 제3자 제공·위탁

- **제3자 제공 없음** — 본 서비스는 민감정보를 제3자에게 제공하지 않습니다. (단, 법령상 수사기관 요청 등 예외)
- **위탁**: 개인정보 처리 위탁 계약에 따라 서비스 운영사(Senior Album)에만 처리를 위탁합니다.
- **국외 이전**: 백업 목적으로 Cloudflare R2(미국)에 **암호화된 상태**로 저장될 수 있습니다. 별도 국외 이전 고지·동의로 갈음합니다.

### 5. 안전성 확보 조치

서비스 운영사는 민감정보에 대해 다음과 같은 보호 조치를 취합니다.
1. **암호화 저장** — 얼굴 벡터, 건강 메모 모두 **AES-256** 암호화 상태로 저장
2. **전송 구간 암호화** — TLS 1.2 이상
3. **접근 통제** — 시설 내 권한 있는 직원 및 해당 입소자의 승인된 보호자에게만 조회 권한
4. **접속 기록 보관** — 민감정보 조회·수정·다운로드 이력 **2년간** 보관
5. **정기 취약점 점검** — 연 1회 이상

### 6. 거부할 권리

**귀하(입소자 본인 또는 법정대리인)는 본 민감정보의 수집·이용에 대한 동의를 거부할 권리가 있습니다.**

**동의를 거부하는 경우의 영향**
- 얼굴 인식 기반 자동 분류 기능 이용 불가 → 시설 직원이 **수동으로만 사진을 분류**해야 하며, 이 경우 다른 입소자·직원의 얼굴이 포함된 사진 공유 시 오분류 위험이 증가할 수 있습니다.
- 건강 메모가 작성되지 않을 경우 시설 직원의 돌봄 참조 정보가 제한될 수 있습니다.
- 민감정보 미동의 상태에서도 **이용약관 및 개인정보처리방침에 기반한 기본 서비스는 이용 가능**합니다.

### 7. 동의 철회

- 이용자는 **언제든지** 서비스 내 "개인정보 설정" 또는 시설 담당자를 통해 민감정보 처리 동의를 철회할 수 있습니다.
- 철회 시 해당 민감정보는 **30일 이내** 파기되며, 파기 완료 후 확인 메시지를 전송합니다.
- 철회 이후에도 서비스의 다른 기능은 계속 이용 가능합니다.

## 법무 검토 시 확인 요청 사항

### 1. 법정대리인 자격 (핵심)
- 치매·의식 저하 상태의 입소자에 대해 **성년후견인 선임이 없는** 경우, 가족 중 누가 법정대리인 역할을 할 수 있는지
- 현장에서 실무적으로 시설장이 "위임받았다"는 확인으로 대체하는 관행이 있는데, 이것이 개인정보보호법상 유효한 동의로 인정되는지
- **대안**: 입소자 측 동의 확인서 + 시설장 확인 **이중 구조**로 설계

### 2. 얼굴 벡터의 "민감정보" 해당성
- 원본 얼굴 사진은 명백한 생체정보
- 특징 벡터(128~512차원 수치)도 민감정보인가? — 개보위는 **원본 복원이 불가하더라도 재식별 가능하면 민감정보**로 보는 추세
- 향후 1:1 매칭 이상으로 확장 시(예: 외부 DB 대조) 재확인 필요

### 3. 동의 거부 시 서비스 품질 저하
- "동의 거부 시 자동 분류 불가" 조항은 **부당한 거부 불이익** 여지 검토 필요
- 수동 분류 옵션을 실제로 제공해야 하며, 그 품질이 자동과 대등하지 않아도 "서비스 자체는 이용 가능"하도록 설계

### 4. 건강 메모의 의료정보 해당성
- 의료법상 "진료기록"에 해당하면 보관 기간·관리 주체 별도 규정 적용
- 본 서비스의 메모는 **돌봄 참조용**으로 의료기록이 아니라는 선 긋기 필요 — 약관/동의서에 명시

### 5. 철회 시 파기 기간
- 초안은 30일로 설정했으나, 개보위는 민감정보에 대해 **즉시 또는 최대 5일**을 권장하는 경향
- 기술적으로 **30일 이내 완전 파기**로 초안 작성 — 단축 가능한지 인프라 담당과 협의 필요
